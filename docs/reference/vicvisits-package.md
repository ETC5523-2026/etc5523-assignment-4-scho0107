# vicvisits: Compare Victorian Public Library Visits per Resident

Provides tools for comparing public library visits per resident across
Victorian library services from 2022-23 to 2024-25. Includes data
prepared from the Public Libraries Victoria Annual Statistical Survey,
functions for comparing library services with statewide benchmarks, and
an interactive Shiny application for exploring results.
